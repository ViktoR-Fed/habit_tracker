# Система управления привычками

## Описание проекта
Веб-приложение для управления привычками с интеграцией Telegram-бота для отправки напоминаний.

## Технологии
- Django 4.2
- Django REST Framework
- Celery + Redis
- PostgreSQL
- Telegram Bot API
- JWT аутентификация

## Установка

1. Клонировать репозиторий
2. Создать виртуальное окружение:
